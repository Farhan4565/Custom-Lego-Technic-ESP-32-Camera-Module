# Custom-Lego-Technic-ESP-32-Camera-Module
A custom designed 3D CAD with 2 pieces to house an ESP-32-S3, a LiPo Battery and a camera.


## Overview
I made this 3D CAD in this web-based CAD software called Tinkercad. I used this software to create the main structure of the 2 pieces. I made this 3D CAD to 3D print at Woodlands Regional Library so that I can have my own custom camera sensor, that I can separately program.


## Design Process
1. I initially wanted a robust case for my ESP-32 that can also connect to my Lego Technic so that I can make use of the ESP-32 more in my robotics.
2. I started measuring all the required measurements of the ESP-32, Camera, LiPo Battery and Lego Technic studs using my Vernier Calipers.
3. Using the measurements, I set the basic dimensions of my custom sensor to make sure I work around it when designing the sensor in the CAD.
4. I planned on how I would design the sensor so I can also easily remove the parts if I wanted to use the components in another place.
5. I started on the CAD model by making a hollow box and splitting it into 2 parts that I would build upon to house the electronic components.
6. I realised my camera is too thick, so the camera would have to stick out of the case a little bit. So taking inspiration from Apple, I made a camera bump with some extra plastic around to protect the camera from impacts on the ground, while also keeping the camera's field of view unobstructed.
7. I added the hole for access to the Universal Serial Bus Type C (USB-C) port on my ESP-32.
8. I included reinforcements to the overall structure to make it easier to print in the 3D printer such as adding wedges to long overhangs to allow for easier and consistent overhang prints.
9. I added the Lego Technic holes to the outer case.


## Features to add in Version 2
